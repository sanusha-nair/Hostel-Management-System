# HostelHub – Hostel Management System

## About the Project
HostelHub is a console-based Hostel Management System developed using C programming. It helps organize daily hostel activities by managing student records, mess information, parcel tracking, and student complaints in one application.

## Features

- **Student Management:** Add, display, search, and delete student records.
- **Mess Management:** Record meals prepared and consumed, calculate food wastage, and maintain meal ratings.
- **Parcel Tracking:** Register incoming parcels and track their collection status.
- **Complaint Management:** Register complaints, assign priorities, track complaint status, and mark complaints as resolved.
- **Dashboard:** Display a summary of hostel activities, including food wastage, pending parcels, and unresolved complaints.

## Technologies and Concepts Used

- C Programming
- Structures
- Pointers
- Dynamic Memory Allocation (`malloc()`, `realloc()`, `free()`)
- File Handling (`fopen()`, `fprintf()`, `fscanf()`, `fclose()`)

## How to Compile and Run

1. Download or clone this repository.
2. Open the project folder in a terminal.
3. Compile the program using GCC:

   ```bash
   gcc C_project.c -o HostelHub
   ```

4. Run the program on Windows:

   ```bash
   HostelHub.exe
   ```

## Data Storage

The application uses file handling to save and retrieve records, helping preserve data between program executions.

## Project Objective

The objective of HostelHub is to reduce manual record-keeping, improve data organization, and make hostel administration more efficient.
